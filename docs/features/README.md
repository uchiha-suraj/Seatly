## Template

Each spec has: **Summary** · **Users and goal** · **Scope** (in / out) · **Behaviour** · **Rules** · **States and errors** · **API and data** · **Acceptance criteria** (IDs only) · **Tests** · **Status and open items**. Copy an existing file for a new feature and give it the next F-number.
